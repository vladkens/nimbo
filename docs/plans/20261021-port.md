# Port

The toolkit comes over from its research repository as a stack of small PRs, bottom up, each one building, tested and readable on its own. The target is the reviewed minimal state; later PRs add widgets and app features when an app needs them.

- [x] 1. Core: the app loop and frame, the scene (rects, rounded corners, borders, shadows, lines), the CPU renderer, PNG, the headless harness; an example of shapes checked by pixels, no OS window yet.
- [x] 2. Windows on macOS (AppKit), Windows (Win32), Linux Wayland and X11: the platform contract, resize, HiDPI, frame pacing, the system light and dark appearance followed live; the shapes example in a real window on each.
- [x] 3. Input: mouse, wheel, keys and layouts, modifiers, cursors, clipboard, the hotkey grammar; an example dragged by mouse and arrows on each backend.
- [ ] 4. Text: system fonts and fallback (CoreText, DirectWrite, FreeType and HarfBuzz), shaping, the glyph atlas; Latin, Cyrillic and emoji on each backend.
- [ ] 5. UI core: the element tree, flex and grid layout, paint, input routing, focus, state, animations, the theme as an open value, behaviour plus look, the button; the counter example and an app-defined theme test.
- [ ] 6. Then, when needed: text fields and IME, lists, menus and containers, the settings form and dialog, tray, global hotkeys and launch at login.
