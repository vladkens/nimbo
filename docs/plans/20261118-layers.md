# Layers, headless controls, features, a stable API

The goal: after 1.0 no app breaks. The crate is three layers an app picks from: the core (OS and renderer), headless behaviour to build a design system on, and the ready one that looks like System Settings. A build compiles only the features it turns on, and no lower module uses a higher one.

Decided by three agents' reports (layers, features, the 1.0 API) and their votes on the merged plan, 2026-11-18, on a09e33f:

- One crate: modules and cargo features, no workspace. The API is methods on `Ui`, which another crate couldn't add, and crates would freeze today's `pub(crate)` items as public API.
- A few large PRs, one idea each; every one is checked by building and testing wavo-app and awake against its branch.
- 0.x releases first; 1.0 once wavo-app and awake have run on the final shape and `examples/custom-look.rs` builds.
- `Color` stays an alias of `[f32; 4]`, documented.
- Defaults: `styled` only. Adding a default later breaks nothing; removing one does.

## 3. A generic environment and a headless layer
- [ ] A typed, scoped `ui.environment(v)` / `ui.env::<T>()` generalising `scopes`; the core knows only ControlSize, disabled and appearance, Theme is one more value the styled layer keeps there; one mechanism with `Ui::slot`
- [ ] ContentMode, FieldKind and `placed` move down; `field_text` and `modal` take colours; a title-bar request in the core replaces `st.toolbar`
- [ ] The `*_behavior` functions into `ui/behavior/`
- [ ] Public building blocks (`ui.behavior(id, Role)`, `animating`, an explicit next id, `stack`, a virtual column, help passing) replace the styled layer's `.st.` reaches and `pub(crate)` calls
- [ ] The `private` rule also catches the core's crate-private fields and types (`ui.next_disabled`, `Node`, `Flow`), a crate-private function called after a `use`, and names a `pub fn` elsewhere shares; child-module paths and globs in the layer rule
- [ ] The styled code under one folder; the baseline's `private` lines gone

## 4. One style per control

## 5. Features
- [ ] `headless` ⊂ `styled` (default); opt-in `tray`, `hotkey`, `paste`, `permissions` (on with hotkey and paste), `instance`, `autostart` (+uninstall, desktop, png), `system` (+hardware, input_source), `png`, `bitmap`, `harness` (tests and examples through a self dev-dependency), `full`; optional objc2 features and frameworks follow
- [ ] `ImageSource` and every gated enum `#[non_exhaustive]`

- [ ] The readme's crate counts; wavo-app and awake turn on what they use
