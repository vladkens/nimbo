## Result

`t!("…")` is a `Localized` translated where it shows (`ui.text`, `FormRow`, `format!`), `t!("…", a, b = x)` and `tn!(one, other, n, …)` a `String` translated now, from the `.po` catalogs an app gives in `Config::localizations`, read lazily, the language the system's or `Main::set_locale`'s. A language tag ends the search at English, the keys' language, so a user who prefers English over Russian gets English. Without arguments `t!` shows its text as it is: `{{` stays doubled.

Skipped for PR 2: nimbo's own strings, `Tag`, menus and `Dialog` taking `Localized`, rebuilding native menus, `AppleLanguages`. msgctxt entries are left out (`t!` has no context). `make api-shots` was not run: it deletes the assets worktree's pictures of blocks not on this branch (other branches' pending ones), so `docs/api.md` and the one new picture were made by hand the same way.

Checked on macOS (languages `["en-US", "ru-IE"]`), on Windows 11 (`["en-US"]`) and on Ubuntu (`LANG=C.UTF-8` gives none, `LANGUAGE=ru:en LANG=ru_RU.UTF-8` gives `["ru", "en", "ru-RU"]`).
