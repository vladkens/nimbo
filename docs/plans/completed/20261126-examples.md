# A few flat examples that show the toolkit and test it

Done: 2026-11-26

Fifteen small examples become five flat ones that show what nimbo can do and double as the test
corpus: `counter` (7GUIs 1), `gallery` (every block, with a Canvas page and the pacing scene),
`custom-look` (a whole look of the app's own), `7guis` (tasks 2–7 on toolbar tabs) and
`messenger` (the window app in breadth and the OS integration). What the removed examples' tests
checked stays checked: through the new examples' tests, or small apps inside `tests/`.

## 1. Tests that keep their own apps
- [x] `tests/fields.rs`, `input.rs`, `lists.rs`, `shapes.rs`, `text.rs`, `hud.rs`, `system.rs`,
  `history.rs`: the removed example's app inside the test file, its tests as they were
- [x] `tests/tray.rs`: the detached tray's scenario and an icon from an SVG file

## 2. The examples
- [x] `7guis`: temperature, flight booker, timer, CRUD, circle drawer and cells on toolbar tabs
- [x] `custom-look`: a dense dark-first tool in a look of its own over the style traits
- [x] `gallery`: a Canvas page (shapes, text, pointer and keys), `gallery -- pace` for
  `make pace`
- [x] `messenger`: chats with bots, a lazy list, a growing composer, a profile panel, search,
  menus, drops, a tray, a settings window, one instance, ru/en, VoiceOver

## 3. The rest
- [x] The removed examples' tests moved: notes and files into the messenger's, settings into
  `tests/settings.rs` with its app
- [x] The readme's list, `agents.md`, `scripts/pace.py`, `scripts/ax-check.py`, the Makefile and
  `docs/plans/20261118-layers.md`
- [x] `make check`, `make test`, each example's shots in light and dark looked at

## Result

Five flat examples, each one file: `counter` (70 lines of code), `7guis` (668), `custom-look`
(369), `gallery` (1382) and `messenger` (1362). The last two are over the ~800 a file keeps:
the gallery is its table of every block, the messenger the window app in breadth; split, they
would be folders. The removed examples' checks live on in apps inside `tests/` (fields, input,
lists, shapes, text, hud, system, history, settings, tray) and in the messenger's tests (the
title bar's toggle and slide from notes, the panels and drops from files). Library changes on
the way: a dialog with no action gets one OK; a prominent icon button keeps the accent's label
colour. Left for the library: a scroll anchored at the bottom (SwiftUI's
`defaultScrollAnchor(.bottom)`), a field that grows with its lines, and a dialog that holds
controls besides buttons (a sheet); the examples do these by hand. The readme's picture is still the old settings
example's, retaken by hand from a real window.
