# The public API in SwiftUI's shape

Done: 2026-11-07

- [x] `ui.help` the only tooltip; `Ui::tooltip` crate-private
- [x] Form rows labelled and described by composed content (`FormRow::new(impl Into<Content>)`), badges and marks ordinary elements in the label; the control named by its plain texts, not read twice, tags read after it
- [x] One `form_section` with a `Section` header and footer
- [x] `form_list`, `reveal_form_row` and `FormRow::selected` gone; the history example on `List`
- [x] `ui.control_size` for the next widget or a container's
- [x] `TextStyle::underline` and `strikethrough` in a `LinePattern`
- [x] The audit's other items: tiles of content, `ui.disabled` on rows and containers, line limits and truncation modes, help marks, one `Picker` with dividers, `Icon::stroke`, `ui.link(label)`, dialog buttons by role, fields without explicit ids
- [x] Choices as enums: menu items and the app's own actions, `ButtonStyle` and `ButtonRole`, `TextLines`, `ColorScheme`, `Axis`, `Axes`, `FieldKind`, `CoordinateSpace` and `UnitPoint`, `MenuPlacement`, typed `Shortcut`s, `FileDialogKind`, `FocusDirection`, `IconPaint`, `Design`, `ListStyle`, `ControlBorder`, and inside `Extent` and `Hit`
- [x] The gallery as a catalog, `docs/api.md` and its pictures from it, the API shape rules in `agents.md`

## Result

The public API follows SwiftUI's shape and the gallery's table keeps `docs/api.md` with it. Skipped: `context_menu` as a modifier (its menu is built from what the element's build just changed, so a closure before it would need that state and the element's borrow at once), `selectable` as a text modifier (the core's `text` would read a widget's state), the segmented control's count tuples, Tabs and Split by index (Rust's borrows), the platforms' internal flag arguments, and `Raster.dark` (dark ink, not a colour scheme).
