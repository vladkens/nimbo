# The public API before 0.1.0: the view's contract written down, renderer and tree internals hidden

Done: 2026-10-31

From section 4 of the redraw research of 2026-10-30 (main at 88536ac), approved 2026-10-31: later performance work (subtree memoization, layout caching, renderer changes) must land without breaking apps, so before 0.1.0 the `view` contract is written down, the renderer's and the tree's internals leave the public API (crate-private where nothing outside needs them, a narrower public accessor where tests or apps do), and `Event` and `FrameStats` become `#[non_exhaustive]`. No behaviour change, no code budget raised. Every user checked first: nimbo's examples and tests, and the downstream app `~/Code/wavo-app` (read only).

- [x] Audit: the `pub` items of `src/lib.rs`'s modules and re-exports that are renderer or tree internals (rustdoc's item list before and after), and who outside the crate uses each (examples, tests, wavo-app).
- [x] The `view` contract on `App::view`, and where views are described (`src/lib.rs`, `src/ui/mod.rs`, `Ui`): it may run several times per frame or not at all, so it only describes the screen from state and reacts to what a pass reports; state changes in responses or `App::event`.
- [x] The renderer crate-private: `mod cpu`; the harness's image keeps its pixels' type public (`harness::Pixels`), `Harness::set_transparent` for the renderer's flag.
- [x] The scene's internals crate-private: `Scene` (with `layers()`), `Layer`, `Sprite`, `Segment`, `ImageUpload`, `Counts` (now test-only), `Quad`'s fields (the renderer's instance layout; apps build it with `Quad::new` and its builders), `ImageId`'s number; `Frame`'s `scene`, `text` and `images` behind `Frame::images`, `Frame::metrics` and `Frame::text_system` (the shaping API for custom paint).
- [x] The runtime crate-private: `Runtime` and `Clock`, the `Harness` fields `rt` and `cpu`; the harness gets what tests and apps used them for (`size`, `mouse`, `hover`, `cursor`, `scroll`, `menu_open`, `built`, `set_focus`, `resize`, `redraw`, `waker`, `clipboard`, `text_input`, `needs_frame`, `due_in`, `set_titlebar`, `a11y_tree`, `text_system`).
- [x] The tree crate-private: `UiState`, `Tree`, `Node`, `Kind`, `Line`, `Measure`, `Canvas`, `Ui::layout` and the frame steps (`Ui::new`, `partial_short`, `rehover`, `shifted`, `paint`, `finish`, `relayout`, `discard`, `tree`), `Cx::ui` (removed, unused), `ui::hit`, `ui::input::drags_window`, `ui::store::Store`, `ui::a11y::Records`, `TextLayout` and `Stop` (reachable only from a tree); `Edit`'s tree indices `#[doc(hidden)]`, so apps keep building it with `..Edit::default()`.
- [x] The text system's atlas protocol crate-private: `ATLAS_SIZE`, `COLOR_ATLAS_SIZE`, `Upload`, `AtlasGlyph`, `Raster`, `GlyphBox`, `SMOOTH`, `FxHasher`, `TextSystem::{new, set_scale, uploads, pending, end_frame, glyph}`, `Line::epoch`; `TextSystem::set_smoothing` test-only (only a unit test called it); `TextSystem::is_color` for the colour-glyph check the text test made through `glyph`.
- [x] `Event` and `FrameStats` `#[non_exhaustive]`; `match`es in examples, tests and wavo-app checked (they end with `_`).
- [x] Docs: no new rustdoc warnings (17 before, 14 after); links to what is now private rewritten.
- [x] wavo-app (a copy in the scratchpad, nimbo patched to this branch): the 12 uses that break and their replacements compile, its hud, window and updater tests pass.
- [x] `make check`, `make test`, `make size ARGS=--check`; the examples' harness shots byte-identical before and after (13 examples, light and dark); the PR with each change (before → after, why, what wavo-app changes) and the `--map` lines.

## Result

The public API lost the renderer (`cpu`), the scene's draw list, the runtime and its clock, the laid-out tree and its measure, and the text atlas protocol; rustdoc lists 49 types, functions and constants fewer (methods aside) and one more (`harness::Pixels`, moved from `cpu`). What tests and apps reached through `Harness::rt` and `Harness::cpu` is now a method on `Harness`, and `Frame::metrics`, `Frame::images` and `Frame::text_system` replace the `text` and `images` fields. `App::view` says how often a view may run and what it may change. `Event` and `FrameStats` are `#[non_exhaustive]`. Nothing draws or behaves differently: the 26 harness shots are byte-identical, every test passes unchanged in what it checks (the list test's bound counts every node now: under 122, main builds 120). wavo-app needs 12 one-line changes, all in its tests and its HUD's paint. Code: ui 3894 / 3900, text 1188 / 1200, core 3962 / 4000; no budget raised. After review, `Harness::set_focus` and `set_titlebar` ask for a frame, so the next one shows them.
