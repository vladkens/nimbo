# A few flat examples that show the toolkit and test it

Fifteen small examples become five flat ones that show what nimbo can do and double as the test
corpus: `counter` (7GUIs 1), `gallery` (every block, with a Canvas page and the pacing scene),
`custom-look` (a whole look of the app's own), `7guis` (tasks 2–7 on toolbar tabs) and
`messenger` (the window app in breadth and the OS integration). What the removed examples' tests
checked stays checked: through the new examples' tests, or small apps inside `tests/`.

## 1. Tests that keep their own apps
- [x] `tests/fields.rs`, `input.rs`, `lists.rs`, `shapes.rs`, `text.rs`, `hud.rs`, `system.rs`,
  `history.rs`: the removed example's app inside the test file, its tests as they were
- [x] `tests/tray.rs`: the detached tray's scenario and an icon from an SVG file

## 2. The examples
- [x] `7guis`: temperature, flight booker, timer, CRUD, circle drawer and cells on toolbar tabs
- [x] `custom-look`: a dense dark-first tool in a look of its own over the style traits
- [ ] `gallery`: a Canvas page (shapes, text, pointer and keys), `gallery -- pace` for
  `make pace`
- [ ] `messenger`: chats with bots, a lazy list, a growing composer, a profile panel, search,
  menus, drops, a tray, a settings window, one instance, ru/en, VoiceOver
